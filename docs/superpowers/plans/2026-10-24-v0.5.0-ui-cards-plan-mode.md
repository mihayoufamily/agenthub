# AgentHub v0.5.0（批次 C 界面三件 + D Agent 卡片 + F 计划态）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把用户提的 5 项界面诉求（模式选择下移、进入工作站动画、token 饼图）、侧栏 Agent 管理卡片（新增 Agent 级 Skill 绑定）、以及"批准前不写盘"的计划态落到 v0.5.0，每步都有断言钉住。

**Architecture:** 界面按既有壳改（`.mode-pill-wrap` / `.wb-mode-title` / `.usage-*` / `.wf-detail`），不新造组件体系；规则一律抽成 `src/shared/**` 纯函数（饼图环数据、Skill 并集、计划态工具分类），所以逻辑层能在纯 Node 下断言；计划态复用既有 `ToolGrant` + `execTool` dispatch + `commandPolicy`/`previewWrites` 的判定形状，不新建底座。

**Tech Stack:** Electron 37.10.3（内嵌 Node 22）、React 18、TypeScript 5.5、zustand、手写 CSS token；验证是自写断言（`verify/*.mjs` + CDP），**没有 Vitest**。

**Spec:** `docs/superpowers/specs/2026-10-23-ui-hardening-agentskills-plan-mode-design.md`（批次 C/D/F 三节 + 决策记录 A 档 14 条 + 验证计划）。本计划是它的论证，spec 是权威：冲突时以 spec 为准并在 ledger 记裁决。

## Global Constraints

- **不引入新依赖**：无图表库（饼图手写 SVG）、无 Vitest、不做插件/扩展点（已延期）。
- **`src/shared/**` 必须保持纯**：不 import `electron`/`node:fs`（已有绊线断言守着，逻辑层要在纯 Node 跑得动）。
- **断言计数只写实测值**：新增/删除断言后必须重跑并把 `verify/run-all.mjs` 的 `min` 抬到新实测值；**削弱或删除断言来变绿一律算缺陷**。汇总行格式必须是 `结果：N PASS / M FAIL`（`PASS_RE`，`verify/run-all.mjs:59`）。
- **提示词注入顺序不变**：`协议 → 项目约定 → 历史记忆 → 角色技能 → 常驻要求`（v0.3.0 拍定）；Agent 级技能**并进"角色技能"层**，不开新层。
- **计划态承诺强度按角色分区**：模型 Agent 的工具层真拦；**CLI 角色不拦，只在计划轮结束后列出改动**。界面措辞绝不能写成"一定没改文件"。
- **尊重"减少动态效果"**：判定式必须是 `prefs?.reducedMotion || prefs?.animations === false` 两条件或运算（与 `Splash.tsx:17-23` 一致），不能只看 `reducedMotion`。
- **界面文案不出现"双环"**（决策记录 A13）；用量页是内圈 harness / 外圈 model，对话栏是单环。
- **停用的 Skill 即使被绑也不注入**（沿用现规则）；Agent 级与角色级、会话级是**并集去重，不加优先级开关**（A12）。
- **每批完成 = `npm run verify`（逻辑）+ `npm run verify:gui`（真机）全绿**，且新增断言覆盖该批行为；发版前重新构建**并部署到 `D:\AgentHub\resources\app`** 再跑真机（`run-all` 只构建不部署，跳过这步等于用旧包验新代码）。
- **真机层写的是本机真实 `%APPDATA%\agenthub`**：改套件前先备份；套件之间要 `waitAppGone`；跑之前确认 `AgentHub.exe` 没在运行（单实例锁会报成 "devtools not ready" 假失败）。
- **`__ahub_debug` 没有 `settings()` 别名**（修复波 B 已删），要用 `openSettings(section?)`。
- 只合本地 main；**推送、打 tag、发 Release 各需用户单独授权**（本轮 spec 的发版切法里 v0.5.0 是第 2 次）。

Create `src/renderer/src/lib/modeTransition.ts`：

```ts
/**
 * 进入工作站的过渡动画该不该播（纯判定，逻辑层断言）。
 * 根因不是观感：大字层原先没有状态位，`Workbench` 每次重挂载都重播——重启恢复、切任务、
 * 切会话都会重挂载，于是"挡事"。只有**真切模式**才该播一次。
 */
export const ENTRY_CAUSES = ['enter-mode', 'hotkey', 'sidebar-switch'] as const
export type EntryCause = (typeof ENTRY_CAUSES)[number]

export function shouldPlayEntry(cause: unknown): cause is EntryCause {
  return typeof cause === 'string' && (ENTRY_CAUSES as readonly string[]).includes(cause)
}
```

```ts
import type { LedgerUsageRow } from './types'

/**
 * 把调用账本折成环数据。
 * 诚实边界先说清：账本只留最近 2000 条、CLI 多数不上报 usage，所以"总计"只代表
 * **ledger 可见调用**；未上报的那些按调用次数单列一格，绝不折算成 token（折了就是编）。
 */
export interface RingSlice {
  key: string
  label: string
  tokens: number
  share: number
  calls: number
  noUsage: number
}

export interface Rings {
  inner: RingSlice[]
  outer: RingSlice[]
  totalTokens: number
  unreportedCalls: number
}

function fold(rows: LedgerUsageRow[], keyOf: (r: LedgerUsageRow) => string, labelOf: (r: LedgerUsageRow) => string): RingSlice[] {
  const m = new Map<string, RingSlice>()
  for (const r of rows) {
    const k = keyOf(r)
    let s = m.get(k)
    if (!s) {
      s = { key: k, label: labelOf(r), tokens: 0, share: 0, calls: 0, noUsage: 0 }
      m.set(k, s)
    }
    s.tokens += r.tokens ?? 0
    s.calls += r.calls ?? 0
    s.noUsage += r.noUsage ?? 0
  }
  const list = [...m.values()].sort((a, b) => b.tokens - a.tokens || b.calls - a.calls)
  const total = list.reduce((a, s) => a + s.tokens, 0)
  // 零 token 不参与归一（否则一个没有任何 usage 的 harness 会分到 0 宽度的扇区，看着像"有但极小"）
  for (const s of list) s.share = total > 0 && s.tokens > 0 ? s.tokens / total : 0
  return list
}

export function buildRings(rows: LedgerUsageRow[]): Rings {
  const real = (rows ?? []).filter((r) => r && typeof r === 'object')
  const inner = fold(real, (r) => r.harness || '（未知接入方）', (r) => r.harness || '（未知接入方）')
  const outer = fold(real, (r) => `${r.harness}|${r.model}`, (r) => r.model || '（未上报模型名）')
  return {
    inner,
    outer,
    totalTokens: real.reduce((a, r) => a + (r.tokens ?? 0), 0),
    unreportedCalls: real.reduce((a, r) => a + (r.noUsage ?? 0), 0)
  }
}

/** 环形扇区路径（零依赖手写 SVG 用；整圆必须拆两段弧，否则起终点重合画不出来） */
export function donutPath(cx: number, cy: number, rOuter: number, rInner: number, a0: number, a1: number): string {
  const span = Math.min(a1 - a0, Math.PI * 2 - 1e-6)
  const pts = (r: number, a: number): [number, number] => [+(cx + r * Math.cos(a)).toFixed(3), +(cy + r * Math.sin(a)).toFixed(3)]
  const halves = span > Math.PI ? 2 : 1
  const step = span / halves
  const seg = (r: number, from: number, to: number, sweep: 1 | 0): string => {
    let d = ''
    for (let i = 0; i < halves; i++) {
      const s0 = from + step * i
      const s1 = s0 + step
      const [x0, y0] = pts(r, s0)
      const [x1, y1] = pts(r, s1)
      d += `A${r} ${r} 0 ${step > Math.PI ? 1 : 0} ${sweep} ${x1} ${y1} `
      void x0
      void y0
    }
    return d
  }
  const [ox, oy] = pts(rOuter, a0)
  const [ix, iy] = pts(rInner, a0 + span)
  return `M${ox} ${oy} ${seg(rOuter, a0, a0 + span, 1)} L${ix} ${iy} ${seg(rInner, a0 + span, a0, 0)} Z`
}
```

```tsx
const PALETTE = ['#b45309', '#0f766e', '#7c3aed', '#b91c1c', '#1d4ed8', '#15803d', '#a16207', '#475569']

/**
 * 零依赖手写 SVG 环（不引图表库）。`double` = 用量页的内圈接入方 + 外圈模型；

 * 按次数单列，绝不折算成 token。
 */
export function DonutRings({ rows, mode = 'double', size = 168, onPickSlice }: {
  rows: LedgerUsageRow[]
  mode?: 'double' | 'mini'
  size?: number
  onPickSlice?: (key: string) => void
}) {
  const { inner, outer, totalTokens, unreportedCalls } = buildRings(rows)
  const c = size / 2
  const arc = (list: RingSlice[], rOut: number, rIn: number, ring: 'inner' | 'outer') => {
    let a = -Math.PI / 2
    return list.filter((s) => s.share > 0).map((s, i) => {
      const a0 = a
      const a1 = a + s.share * Math.PI * 2
      a = a1
      const d = donutPath(c, c, rOut, rIn, a0, a1)
      return (
        <path
          key={`${ring}-${s.key}`}
          d={d}
          fill={PALETTE[i % PALETTE.length]}
          data-ring={ring}
          data-slice={s.key}
          onClick={onPickSlice ? () => onPickSlice(s.key) : undefined}
          style={{ cursor: onPickSlice ? 'pointer' : 'default' }}
        >
          <title>{`${s.label}：${s.tokens.toLocaleString()} token（${Math.round(s.share * 100)}%）· ${s.calls} 次`}</title>
        </path>
      )
    })
  }
  return (
    <div className="usage-rings" style={{ display: 'flex', gap: 12, alignItems: 'center' }}>
      <svg width={size} height={size} viewBox={`0 0 ${size} ${size}`} role="img" aria-label="token 用量占比">

          <>
            {arc(inner, c * 0.62, c * 0.34, 'inner')}
            {arc(outer, c * 0.98, c * 0.7, 'outer')}
          </>
        ) : (
          arc(inner, c * 0.98, c * 0.6, 'inner')
        )}

    </div>
  )
}
```

```ts
import type { Skill } from './types'

/**
 * 三层 Skill 绑定的合并口径（Agent 级 ∪ 会话手动引用 ∪ 角色绑定）。
 * 用户明确否掉了"优先级开关"（spec 决策记录 A12），所以这里只有并集与去重，没有谁覆盖谁。
 */
export function unionSkillIds(...layers: Array<Array<string | null | undefined> | null | undefined>): string[] {
  const out: string[] = []
  for (const layer of layers) {
    if (!Array.isArray(layer)) continue
    for (const id of layer) {
      if (typeof id === 'string' && id && !out.includes(id)) out.push(id)
    }
  }
  return out
}

/** 停用的 skill 即使被绑也不注入（与 `SettingsPage` 开关语义、`skillsBlockFor` 现规则同口径） */
export function partitionSkillsForInjection(
  all: Skill[],
  ids: string[] | undefined,
  mode: 'auto' | 'reference'
): { injected: Skill[]; listed: Skill[] } {
  const picked = (Array.isArray(ids) ? ids : [])
    .map((id) => (Array.isArray(all) ? all.find((s) => s && s.id === id) : undefined))
    .filter((s): s is Skill => !!s && s.enabled !== false)
  return mode === 'auto' ? { injected: picked, listed: [] } : { injected: [], listed: picked }
}
```

```ts
 * 计划态：在用户批准"怎么做"之前，任务不产生文件改动，交付物是一份计划。
 * 承诺强度只到**模型 Agent 的工具层**——那部分执行权在 AgentHub 手里，"禁止"是真拦。

export interface PlanVerdict {
  allowed: boolean
  reason: string
}

export function planModeVerdict(tool: string, planMode: unknown): PlanVerdict {
  // 只有显式 true 才启闸：脏值/缺省一律按"非计划态"，避免一个字符串把用户的正常工具全关掉

  }
  return { allowed: true, reason: '' }
}
```

Create `src/shared/dir-delta.ts`：

```ts
/**
 * 计划轮结束后，把"开工前的目录清单"与"现在的清单"折成差集。
 * CLI 角色的写盘由它自己的子进程做，AgentHub 拦不到——只能事后如实列出来（spec 批次 F）。
 * 只算路径集合，不读内容、不删任何东西。
 */
const key = (s: unknown): string => (typeof s === 'string' ? s.trim().replace(/\\/g, '/').toLowerCase() : '')

export function dirDelta(before: unknown, after: unknown): { added: string[]; removed: string[] } {
  const b = (Array.isArray(before) ? before : []).map(key).filter(Boolean)
  const a = (Array.isArray(after) ? after : []).map(key).filter(Boolean)
  const bs = new Set(b)
  const as = new Set(a)
  return { added: a.filter((x) => !bs.has(x)).sort(), removed: b.filter((x) => !as.has(x)).sort() }
}
```
