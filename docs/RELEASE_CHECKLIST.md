# 发布检查清单（Release Checklist）

每次发布前逐项核对。**未验证的项目必须如实标注，不得写成已支持。**

## 构建与产物

- [ ] `npm run typecheck` 通过
- [ ] `npm run build` 通过（tsc main + tsc/rollup renderer）
- [ ] `npm run dev` 实机启动无报错，开屏 → 欢迎页 → 首页正常
- [ ] `npm run pack:portable` 产物可运行；或 `npm run dist` 安装包在干净机器安装成功
- [ ] 图标已替换（当前无自定义 icon，electron-builder 会用默认 Electron 图标——发布前必须补 `build/icon.ico`）

## 功能冒烟（参照规格 §23）

- [ ] 首次启动完整欢迎流程；跳过动画（Esc）
- [ ] 后续启动恢复上次工作区
- [ ] 中文输入法：候选词确认不误发送
- [ ] Enter 发送 / Shift+Enter 换行 / 设置切换后生效
- [ ] 草稿在页面切换与重启后保留
- [ ] Agent 添加（演示 / 自定义模型连接测试 / 扫描候选）
- [ ] 管理顺序：拖拽 + 上下移 + 保存持久化
- [ ] Shift+滚轮切换（节流、边界停止、HUD 提示）
- [ ] 工作流演示全流程：规划 → 执行 → 审核 → 返工 → 人工确认 → 交付
- [ ] 返工达到上限：保留成果并提示未完成项
- [ ] 停止任务 / 超时停止
- [ ] 运行中切换模式：红色警告 + 默认焦点安全项
- [ ] 重启后任务记录恢复且标记"状态未知"
- [ ] 配置导出不含 API Key；导入后需重新授权的项目有提示
- [ ] 断网时自定义模型连接测试给出可读错误

## 安全与隐私

- [ ] 仓库内无用户名、磁盘路径、密钥、个人配置（`git grep` 复查）
- [ ] 日志不含秘密
- [ ] API Key 只存系统凭据存储

## 文档与许可

- [ ] README 功能状态表与实际一致
- [ ] 版本号已更新（package.json / electron-builder 产物名）
- [ ] **许可证已由项目所有者确认并添加 LICENSE 文件**（当前为待定占位——发布公开仓库前必须解决）
- [ ] 平台支持声明：仅写已验证的平台
