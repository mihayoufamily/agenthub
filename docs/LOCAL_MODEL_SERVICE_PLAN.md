# 方案：本地三模型内置到 AgentHub 对外提供服务

> 状态：方案已确认架构，待实施。本文档是跨会话的工作交接文档——新窗口从这里继续。
> 日期：2026-10-25。提出人：用户（marypoem）。

## 需求原话与解读

用户本地部署了三个模型（`D:\local-llm`），希望：
1. 内置到 AgentHub，别人安装后**直接能看到**这三个模型；
2. 用户的模型服务开着时，别人**能直接调用**；
3. **分发 API Key** 给使用者。

已确认的关键歧义裁决：这里的"内置"是**内置入口与配置**，不是把模型权重打进安装包（物理上不可行，见下）。

## 三个物理现实（方案的前提，不可绕过）

1. **模型权重进不了安装包**：三个模型哪怕都是 7B 级，权重也是几十 GB——GitHub Release 单文件 2GB 上限。能内置的只有入口和配置。
2. **用户的电脑不在使用者的网络路径上**：使用者从 GitHub 下载 AgentHub，他们的请求必须能到达用户的机器——需要公网可达入口（用户基础设施，非 AgentHub 代码）。
3. **API Key 不能进安装包/仓库**：发行版任何人可解包，key 进包 = 三模型向全世界免密开放。Key 必须经带签发/吊销能力的网关单独分发。

## 总体架构

```
使用者的 AgentHub                      用户侧
┌──────────────┐   https+key   ┌─────────────────────┐
│ 内置"官方模型" │ ────────────→ │ 公网入口（隧道/转发）  │
│ 入口(端点预置) │                └──────────┬──────────┘
│ 用户粘贴 key  │                            ↓
└──────────────┘                ┌─────────────────────┐
                                │ 网关 new-api          │
                                │ (发key/限流/用量/吊销) │
                                └──────────┬──────────┘
                                           ↓
                                ┌─────────────────────┐
                                │ 三个模型              │
                                │ (D:\local-llm 服务化) │
                                └─────────────────────┘
```

AgentHub 调用走**现有的"自定义模型（OpenAI 兼容）"通道，模型调用代码零新增**。

## 分工

### 用户侧（三层，按顺序搭）

1. **模型服务化**：确认三个模型都经 OpenAI 兼容接口对外服务（llama.cpp server / Ollama / vLLM / LM Studio 均可）。⚠ 待用户确认现状：用的什么服务化、端口多少。
2. **网关（发 Key 的关键）**：架 **new-api**（或 one-api）——OpenAI 兼容网关：给每个使用者签发独立子 key、按 key 限流限额、用量统计、随时吊销。三个模型注册成三个"渠道"。**真实 key 永不外发，发的都是网关子 key**。
3. **公网入口**：家里宽带无公网 IP 也可用 **Cloudflare Tunnel**（免费、自带 https、无需端口映射）；或有 VPS 则 frp 转发。

### AgentHub 侧（代码部分，待实施）

- **内置"官方模型"入口**：像 builtin-skills 一样内置官方服务配置（端点 + 三模型的名称/描述/上下文长度），添加 Agent 流程里一键生成预置好的模型 Agent，用户只填 key；
- **清单走注册表**：端点与模型清单不放死在代码里——新建 `agenthub-models` 注册表仓库（同 agenthub-skills 模式），用户改模型/换端点不用重新发版，应用拉注册表刷新；
- **体验细节**：连接测试、用量显示（走现有账本）、401 → "key 无效或已吊销，联系服务提供方"的明确提示。

## 成本与风险（提前想清楚）

- **带宽**：token 持续流出。家庭宽带上行 30Mbps 时，7B 模型同时服务 2~3 人即到顶——非代码可优化；
- **滥用**：key 会外传。网关必须按 key 设额度（new-api 原生支持），否则电费在替别人跑；
- **合规**：对外提供模型服务涉及备案与内容责任。朋友间共用与公开分发是两回事，尺度由用户定。

## 分期

- **第一期（最小可用）**：用户搭 new-api + 隧道，手工发几个 key；AgentHub 端做"官方模型内置入口 + 注册表拉清单"。
- **第二期**：官方服务状态页（模型在线/离线显示）、用量展示优化、key 过期友好提示。
